# My Robot Package

This repository contains the default URDF definition for a robot to be used in ENPH 353 competitions using Gazebo Sim. Students should feel free to modify it as 

The robot is a differential drive 2-wheel and caster robot. It also has a default camera at the front.

The package also contains a launch file for visualizing the robot in RViz.

This robot will be used in combination with the ENPH 353 competition package (for example the [2026 competition package](https://github.com/ENPH353/2026_competition).)
